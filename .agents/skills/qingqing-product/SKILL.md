# 青轻生活馆产品规范

## 1. 项目定位

项目名称：青轻生活馆

项目类型：

- Flutter 跨平台中型商业 App
- 会员制电商
- 直播电商
- 积分商城
- 本地生活服务
- 会员权益
- 购酒送服务

产品体验参考东方甄选类直播电商 App，但不得复制其品牌资源、商标、版权素材。

目标：

- 生产级代码
- 中大型项目架构
- 可长期维护
- 支持后续直播、秒杀、促销引擎扩展
- API 后端已经存在
- 本项目只负责 Flutter 客户端
- 不得自行创建后端服务

# 4. 核心业务关系

商品：

商品 → SKU → 购物车 → 结算 → 订单 → 支付 → 发货 → 收货 → 售后

会员：

用户 → 会员等级 → 会员权益 → 商品权限 → 服务权益 → 积分权益

积分：

积分账户 → 积分流水 → 积分规则 → 积分商城 → 积分兑换

购酒送服务：

商品购买 → 订单金额 → 权益规则 → 服务权益 → 服务预约

活动：

Banner → 活动 → 专题 → 商品/服务

# 5. 动态配置原则

以下内容不得硬编码：

- 首页 Banner
- 金刚区
- 分类名称
- 分类图标
- 商品推荐
- 活动
- 专题
- 优惠
- 会员权益
- 服务
- 积分商城商品
- 商品展示规则

后端返回什么，客户端按照配置渲染。

---

# 6. 页面设计原则

页面必须具备：

- Loading
- Empty
- Error
- Content
- Pull to refresh
- Pagination（需要分页的页面）
- 网络异常处理

禁止只实现正常数据状态。

---

# 7. 不重复造页面

相同业务使用参数化页面。

例如：

OrderListPage：

- 全部
- 待付款
- 待发货
- 待收货
- 待评价

ProductListPage：

- 青藏特产
- 电商特供
- 特色商城
- 特价商品
- 猜你喜欢

使用同一个页面。

ServiceListPage：

- 管家
- 高尔夫
- 跑步
- 自行车

使用同一个页面。

# 9. 开发原则

任何功能开发之前：

1. 先检查现有代码
2. 复用已有组件
3. 复用已有 Repository
4. 复用已有 Model
5. 复用已有 Provider
6. 不重复创建同类组件
7. 不随意修改公共组件
8. 修改公共组件必须评估影响范围

禁止为了完成一个页面而破坏整体架构。
