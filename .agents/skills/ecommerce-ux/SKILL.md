# UX

## 1. 所有网络操作

必须有明确反馈：

点击
→ Loading
→ 成功 / 失败

---

# 2. 防重复提交

提交订单、支付、兑换、预约必须：

点击后立即锁定按钮。

---

# 3. 商品

商品列表：

- 下拉刷新
- 上拉加载
- 加载状态
- 空状态
- 网络错误

---

# 4. 购物车

用户修改数量后：

- 即时更新 UI
- 更新金额
- 更新优惠
- 更新运费
- 更新积分抵扣

---

# 5. 结算

结算页面必须明确：

商品金额
+
运费
-
优惠券
-
积分抵扣
=
应付金额

---

# 6. 订单

支付成功后：

不得简单 Toast。

进入：

支付结果页面

并提供：

查看订单
继续购物

---

# 7. 购酒送服务

加入购物车后，如果接近权益门槛：

主动提示：

“再购买 XX 元即可获得 XX 服务权益。”

提交订单时再次校验资格。

后端返回最终资格结果，客户端不得自行决定最终资格。

---

# 8. 积分

积分即将过期时：

在：

- 我的
- 积分页
- 积分商城

适当位置展示提醒。

---

# 9. 空状态

所有列表必须设计 Empty State。

例如：

没有订单
没有优惠券
没有积分记录
购物车为空
没有预约
没有售后
