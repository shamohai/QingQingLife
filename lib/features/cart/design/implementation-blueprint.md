# Cart Implementation Blueprint

Reference viewport: 440 logical pixels wide. The page must remain usable down to 320 logical pixels.

## Structure

CartPage

- CartPageHeader: back action, page title, management toggle, local address selector.
- CartItemsPanel: one rounded white surface containing every cart row.
- CartItemCard: selection, supplied product image, self-operated badge, specification tags, integer-cent price, quantity controls.
- CartRecommendationSection: centered heart heading and a lazy two-column product grid.
- CartRecommendationCard: supplied square product image, member badge, title, tags, price and local add-to-cart action.
- CartBottomBar: select all, computed payable amount, computed savings and checkout action; management mode exposes clear-all and selected-delete actions.

## State Boundary

`cartPageProvider` owns this page's local Mock state. The service cart owns a separate `serviceCartDataProvider`; the two features do not share provider state.

The page uses integer cents. Each selected unit receives a fixed CNY 10 local Mock promotion so the initial four-item state reports CNY 40 saved and CNY 3160 payable.

## Asset Boundary

The exact Lanhu product images are retained in `design/source-assets` for reference and embedded as generated byte constants inside the cart feature. This avoids browser CORS failures and requires no global pubspec or asset-directory change.

## Responsive Rules

- Header and settlement bar are SafeArea-aware.
- Cart image size scales from 96 to 112 based on available panel width.
- Recommendation image width follows the two-column grid width.
- Bottom CTA scales from 118 to 156 wide.
- Long text is constrained with explicit line counts and ellipsis.

## Functional Semantics

- Back uses the current Navigator when possible and otherwise returns to `/`.
- Address selection is a local modal selector.
- Management mode exposes selected-item deletion with confirmation.
- Management mode exposes a separate clear-all action with its own confirmation copy.
- Successful deletion and clear-all operations exit management mode; an empty cart hides the bottom action bar.
- Recommendation carts add or increment a matching local item.
- Checkout opens a local order summary; it does not call a payment or backend API.
